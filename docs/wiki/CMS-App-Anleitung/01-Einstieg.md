# 🚀 Einstieg & Überblick

## Was ist die E-Motion Website?

Die Website ist das **öffentliche Aushängeschild** des Rennteams. Besucher können hier alles über das Team, die Fahrzeuge, Erfolge, News und Sponsoren erfahren.

---

## Wie funktioniert das technisch? (einfach erklärt)

Stell dir die Website wie ein **Buch** vor:

```
📖 Das Buch (Website)
 ├── 📝 Die Texte & Inhalte  → in /content/ Ordnern gespeichert
 ├── 🖼️  Die Bilder           → in /public/uploads/ gespeichert
 └── 🎨 Das Design          → vom Entwickler gebaut, nicht änderbar
```

Du als Redakteur bearbeitest nur **Texte und Bilder** – das Design bleibt immer gleich.

---

## Wer darf was?

| Rolle | Was darf ich? |
|-------|---------------|
| **Admin** | Alles: Inhalte bearbeiten, Bilder hochladen, Benutzer verwalten |
| **Redakteur** | Inhalte bearbeiten und Bilder hochladen |
| **Besucher** | Nur lesen (normale Website-Besucher) |

## Welche Seiten gibt es auf der Website?

| Seite | URL | Was steht dort? |
|-------|-----|------------------|
| Startseite | `/` | Überblick und Highlights |

| Fahrzeuge | `/fahrzeuge` | Unsere Rennwagen (2012–heute) |

| Blog | `/blog` | Längere Artikel & Berichte |
| Erfolge | `/erfolge` | Wettbewerbsergebnisse |
| Formula Student | `/formula-student` | Erklärung des Wettbewerbs |
| Sponsoren | `/sponsoren` | Unsere Partner |
| Kontakt | `/kontakt` | Kontaktformular |
| Mitmachen | `/mitmachen` | Bewerbungsformular |

---

## Wie läuft eine Änderung ab?

```
Du gibst eine Änderung ein
        ↓
Klickst auf "Speichern"
        ↓
Die Änderung wird auf GitHub gespeichert (automatische Sicherung)
        ↓
Die Website aktualisiert sich (nach wenigen Sekunden sichtbar)
```

> ✅ **Sicherheit:** Jede Änderung wird mit Datum und Uhrzeit gespeichert.  
> Falls etwas schiefläuft, kann ein Admin die letzte Version wiederherstellen.

## ⚡ Schnellstart

1. Gehe zu **`/admin`** auf der Website (z.B. `https://e-motion-rennteam.de/admin`)
2. Logge dich mit Benutzername + Passwort ein
3. Wähle links den Bereich, den du bearbeiten möchtest
4. Änderungen vornehmen → **Speichern** klicken → fertig!

> 💡 **Tipp:** Alles wird automatisch auf GitHub gesichert – du kannst nichts dauerhaft kaputt machen.

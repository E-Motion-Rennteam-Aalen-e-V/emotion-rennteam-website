# 33 – Tastatur-Shortcuts Cheatsheet

## GitHub im Browser

### Navigation

| Shortcut | Funktion |
|----------|---------|
| `T` | Dateisuche öffnen |
| `W` | Branch wechseln |
| `L` | Zu einer Zeile springen |
| `Y` | Permanentlink zur aktuellen Dateiversion |
| `B` | Blame-Ansicht öffnen (wer hat was geschrieben) |
| `?` | Alle Tastaturkürzel anzeigen |
| `/` | Suchfeld fokussieren |
| `S` | Suchfeld öffnen |
| `G` dann `C` | Gehe zu Code |
| `G` dann `I` | Gehe zu Issues |
| `G` dann `P` | Gehe zu Pull Requests |
| `G` dann `A` | Gehe zu Actions |

### In der Dateiansicht

| Shortcut | Funktion |
|----------|---------|
| `E` | Datei bearbeiten (Edit) |
| `Ctrl+F` | In Datei suchen (Browsersuche) |

---

## GitHub Web Editor (github.dev)

### Bearbeitung

| Shortcut | Funktion |
|----------|---------|
| `Ctrl+S` | Datei speichern |
| `Ctrl+Z` | Rückgängig |
| `Ctrl+Y` | Wiederholen |
| `Ctrl+C` | Kopieren |
| `Ctrl+X` | Ausschneiden |
| `Ctrl+V` | Einfügen |
| `Ctrl+A` | Alles markieren |

### Navigation im Editor

| Shortcut | Funktion |
|----------|---------|
| `Ctrl+P` | Datei öffnen (schnelle Suche) |
| `Ctrl+F` | In aktueller Datei suchen |
| `Ctrl+H` | Suchen und ersetzen |
| `Ctrl+Shift+F` | In allen Dateien suchen |
| `Ctrl+G` | Zu Zeile springen |
| `Ctrl+Shift+P` | Befehlspalette öffnen |

### Markdown

| Shortcut | Funktion |
|----------|---------|
| `Ctrl+Shift+V` | Markdown-Vorschau öffnen |
| `Ctrl+B` | **Fett** |
| `Ctrl+I` | *Kursiv* |

### Git im Web Editor

| Shortcut | Funktion |
|----------|---------|
| `Ctrl+Shift+G` | Git-Seitenleiste öffnen |

---

## Browser-Shortcuts (allgemein, nützlich für GitHub)

| Shortcut | Funktion |
|----------|---------|
| `Ctrl+Shift+R` | Seite neu laden (Cache leeren) |
| `Ctrl+F` | Auf der Seite suchen |
| `Ctrl+T` | Neuer Tab |
| `Ctrl+W` | Tab schließen |
| `Alt+←` | Zurück (Seite zurück) |
| `Alt+→` | Vorwärts (Seite weiter) |
| `F5` | Seite neu laden |

---

## Mac-Varianten (statt Ctrl → Cmd)

Auf einem Mac: überall wo `Ctrl` steht, stattdessen `Cmd` (⌘) verwenden.

| Windows/Linux | Mac |
|--------------|-----|
| `Ctrl+S` | `Cmd+S` |
| `Ctrl+Z` | `Cmd+Z` |
| `Ctrl+C` | `Cmd+C` |
| `Ctrl+F` | `Cmd+F` |
| `Ctrl+Shift+R` | `Cmd+Shift+R` |

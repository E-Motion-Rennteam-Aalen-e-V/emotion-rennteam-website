# 23 – GitHub Mobile App

## Überblick

Die offizielle **GitHub Mobile App** für iOS und Android erlaubt dir, unterwegs auf das Repository zuzugreifen, Benachrichtigungen zu verwalten und einfache Aktionen durchzuführen.

**Download:**
- iOS: App Store → "GitHub"
- Android: Google Play Store → "GitHub"

---

## Einrichtung

1. App herunterladen und öffnen
2. **"Sign in with GitHub"** tippen
3. Browser öffnet sich → GitHub-Konto auswählen → Bestätigen
4. Zurück in die App → fertig

---

## Was du auf dem Smartphone erledigen kannst

| Funktion | Verfügbar? |
|----------|-----------|
| Issues lesen und kommentieren | ✅ |
| Pull Requests reviewen | ✅ |
| Benachrichtigungen verwalten | ✅ |
| Dateien lesen (Code/Content) | ✅ |
| Bilder hochladen | ✅ (eingeschränkt) |
| Dateien direkt bearbeiten | ⚠️ Eingeschränkt |
| Commits erstellen | ⚠️ Eingeschränkt |

> Für umfangreiche Änderungen: am Laptop/Desktop arbeiten.

---

## Benachrichtigungen auf dem Smartphone

### Push-Notifications aktivieren:

1. App öffnen → Profil-Icon (unten rechts)
2. **"Settings"** → **"Notifications"**
3. Aktivieren:
   - "Participating and @mentions" → Push aktivieren
   - Optionale Channels nach Bedarf

### Benachrichtigungen lesen:

```
┌─────────────────────────────────────────────────────────┐
│  🔔 Notifications                                       │
│                                                         │
│  ● Issue #22: Bild Sponsor fehlt         vor 10 min    │
│  ● @du-wurdest-erwähnt                   vor 1h        │
│  ● PR #113 wurde gemergt                 vor 3h        │
│                                                         │
│  [Alle als gelesen markieren]                           │
└─────────────────────────────────────────────────────────┘
```

---

## Repository auf dem Smartphone durchsuchen

1. Suche (Lupe) unten in der Navigation
2. Repository-Name eingeben: `E-Motion-Rennteam`
3. Repository öffnen
4. Ordner und Dateien durchsuchen und lesen

---

## Issue unterwegs erstellen

1. Zum Repository navigieren
2. **"Issues"** Tab
3. **"+"** Button oben rechts
4. Titel und Beschreibung eingeben
5. Labels und Assignees optional setzen
6. **"Submit"**

---

## Auf Review-Kommentare antworten

1. Benachrichtigung öffnen
2. Kommentar lesen
3. Antworten direkt in der App möglich

---

## Tipp: Widget für Benachrichtigungen

Auf iOS: GitHub-Widget zum Homescreen hinzufügen → siehst Benachrichtigungen ohne die App zu öffnen.
